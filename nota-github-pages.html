Cómo publiqué mi web con GitHub Pages

28 de septiembre de 2026

Quería una web propia donde reunir mi CV, mis proyectos y unas notas. Con GitHub Pages salió gratis y sin servidor, y esto es lo que hice.

  1. Creé un repositorio público con el nombre exacto mi-usuario.github.io.
  2. Subí mis archivos, con una página principal llamada index.html.
  3. En Settings → Pages activé la publicación desde la rama principal.
  4. En pocos minutos la web estaba en línea en mi-usuario.github.io.

El siguiente paso es conectarle un dominio propio.
